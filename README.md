# Travel and Tourism Management System

## Project Overview
The Travel and Tourism Management System is a menu-driven application developed using C programming. The project is designed to provide a simple and organized way to manage travel and tourism booking activities.
The system allows the user to select a travel destination, choose suitable transportation and select a travel package according to their requirements. Based on the selected options and booking details, the system calculates the applicable charges, discounts and taxes and displays the final booking information.
This project demonstrates how C programming concepts can be applied to develop a practical management system.

## Problem Statement
In a travel booking process, users need to consider different factors such as destination, transportation, travel packages, number of travelers and total cost. Handling these details manually can be time-consuming and may lead to calculation errors.
The purpose of this project is to develop a simple computerized system that manages these basic travel booking requirements through a menu-driven interface.

## Project Objective
The main objectives of this project are:
- To develop a simple Travel and Tourism Management System using C programming.
- To provide a menu-driven interface for the user.
- To allow users to select destinations and transportation options.
- To provide different travel package options.
- To calculate the total booking cost automatically.
- To apply applicable GST and discounts.
- To validate important user information such as phone number.
- To display the final booking details in an organized manner.
- To apply C programming concepts to a practical real-world problem.

## Motivation
Travel and tourism involves managing different types of information such as destinations, transportation, packages, customer details and booking costs.
This project was developed to understand how such requirements can be converted into a computerized system using C programming. It also provides practical implementation of important C concepts such as structures, arrays, functions and linked lists.

## Features
### 1. Destination Selection
The system provides different destination options from which the user can select the destination according to their travel requirement.

### 2. Transportation Selection
The user can select the required mode of transportation. The transportation cost is considered while calculating the final booking amount.

### 3. Travel Package Selection
The system provides travel package options. The selected package is included in the booking and its cost is considered in the final calculation.

### 4. Booking Management
The system accepts required booking information from the user and maintains the booking details during the execution of the program.

### 5. Cost Calculation
The system calculates the booking cost based on the selected destination, transportation, package and number of travelers.

### 6. Discount Calculation
The system applies discounts according to the number of people in the booking.
- 10% discount for a minimum of 4 people.
- 20% discount for more than 10 people.

### 7. GST Calculation
Applicable GST is calculated and added to the booking amount before displaying the final cost.

### 8. Phone Number Validation
The system validates the customer's phone number to ensure that the entered number follows the required format.

### 9. Booking Details Display
After processing the booking, the system displays the selected travel details and the calculated final amount.

## Working of the System
The system follows a menu-driven approach.
1. The program starts and displays the available menu options.
2. The user selects the required travel destination.
3. The user selects the preferred transportation.
4. The user selects a suitable travel package.
5. The required customer and booking details are entered.
6. The system calculates the applicable charges.
7. Discount is applied according to the number of travelers.
8. GST is calculated on the applicable amount.
9. The final booking cost is calculated.
10. The system displays the complete booking details.

## Calculation and Billing
The system considers the selected travel options and number of travelers while calculating the total cost.
The applicable discount is calculated based on the number of people in the booking. After applying the discount, GST is calculated and the final payable amount is displayed.
This reduces manual calculation and helps provide consistent billing results.

## Validation
Input validation is included to improve the reliability of the system.
The phone number entered by the user is checked according to the required 10-digit format. This helps prevent invalid phone numbers from being accepted as booking information.
